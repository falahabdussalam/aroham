# Aroham Foundation Website

Official website for **Aroham Foundation** & **Aroham UniMates** built from the Figma prototype specification.

## Tech Stack
- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS
- **Typography**: Montserrat (Google Fonts)
- **Icons**: Lucide Icons
- **Brand Assets**: Official Aroham Foundation vector emblem & high-res artwork

## Features
- **5 Complete Interactive Pages**:
  - `Home`: Hero showcase, live upcoming event spotlight, two pillars overview, sisterhood quote & mentorship growth map, CTA banner.
  - `About Us`: Bolster Girls Campus heritage, Genesis narrative, Foundational Timeline (2025), Guiding Light (Mission & Vision), Executive Committee.
  - `Events & Guidance Sessions`: Live events schedule, past milestones archive with chronological sorting, speaker profiles, and photo galleries.
  - `Aroham UniMates`: 1:1 mentorship philosophy, verified alumnae directory with search and academic stream filters, activities overview, and registration portals.
  - `Contact Us`: Direct communication channels, active Instagram feed preview, inquiry submission form, and FAQ accordion.
- **Interactive Modals**:
  - Event seat registration modal
  - 1-on-1 mentor match request modal
  - "Get Involved" sisterhood application modal
- **Attribution**: Includes "Powered by [Ziqx](https://ziqx.cc)" in the footer.

## Getting Started

### Install Dependencies
```bash
npm install
```

### Run Development Server
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```

### Preview Production Build
```bash
npm run preview
```
